# Wedding Countdown for Android 4+

אפליקציית ספירה לאחור לתאריך חתונה, עם ממשק עברי, תמונות מקומיות והתראות לבחירה.

## Features

- Three selectable themes: Luxury Gold, Soft Minimal, and Midnight.
- Offline daily quote that changes at local midnight.
- Countdown with a visual progress ring.
- 100/50/30/14/7/3/1-day milestones and event-day celebration.
- Local photo gallery and automatic home-screen slideshow.
- Daily widget refresh and notification preferences.
- Local-only storage; no account or network connection required.

## Build

Open the project in Android Studio or run `gradle assembleDebug`.

Minimum system: Android 4.0 (API 14) and up.

The checked-in keystore is a **development/test signing key only**, used to keep sideloaded test APK updates consistent. Do not use it for a public production release or Google Play. Create a private production signing key for store distribution.
